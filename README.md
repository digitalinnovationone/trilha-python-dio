# Trilha Python DIO
Este repositório contém os desafios práticos da formação Python da DIO.

## Projeto Bancário - Versão 2

Este projeto é uma evolução do desafio bancário proposto no módulo de fundamentos. Ele foi refatorado com foco em boas práticas, modularização e escalabilidade.

### Melhorias implementadas na versão 2:

- Organização do código em funções reutilizáveis;
- Uso de listas para armazenar múltiplos usuários e contas;
- Validação de dados ao cadastrar contas e usuários;
- Separação clara de responsabilidades no código;
- Mensagens mais informativas e tratamento básico de erros.
